# Praktikum-4-PABW-
### ParkTrack - Sistem Manajemen & Reservasi Parkir Cerdas (Modul 4)

Aplikasi manajemen dan reservasi parkir berbasis web menggunakan Laravel 12, MySQL, Tailwind CSS, dan Bootstrap Icons.

#### Fitur Utama:
- Halaman Tamu: Dashboard status ketersediaan slot, formulir reservasi slot, cek status tiket & QR code, info area, dan simulasi denda.
- Halaman Petugas: Dashboard kapasitas & pendapatan, daftar parkir & riwayat reservasi (Eloquent & Seeder Faker `id_ID`), cek pengguna, dan pencatatan pelanggaran/denda.
- Autentikasi peran Petugas (`officer`) dan Tamu/User.
